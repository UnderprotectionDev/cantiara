# Cantiara Web Capture extension

WXT browser extension (React) that sends explicit web captures from the active tab to the Cantiara Capture Inbox.

- `bun run dev` / `bun run dev:firefox`: start WXT with hot reload.
- `bun run build` / `bun run build:firefox`: production build into `.output/`.
- `bun run zip` / `bun run zip:firefox`: package for store upload.
- `bun run check-types`: type-check the extension.
