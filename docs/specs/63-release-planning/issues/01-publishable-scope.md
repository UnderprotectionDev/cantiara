# 01 — Yayımlanacak kapsam olarak Proje Sürümü

**What to build:** Kurucu bir Projeye ait `Project Release` ana kaydı oluşturur; kapsam İş üyelikleridir. Aynı Projenin birden fazla repository'sinden tag, GitHub Release kaydı ve ortam bağları eklenebilir; ortak çalışma alanı Sürümü yoktur. Kayıt Kilometre Taşı veya Odak Dönemi değildir; otomatik kapsam doldurma veya skor kapısı yoktur. İsteğe bağlı erişim ve sonuç hipotezi ayrı alanlardır, yayın kapısı değildir. Yerleşik yayın tarihi alanı yoktur.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Sahiplik tam bir Proje; çapraz Proje Sürümü reddedilir.
- [ ] Tip ve UI `Project Release`; Milestone/Focus Period komutları bu kaydı yazmaz.
- [ ] Hipotez alanları erişim ile sonucu ayrı tutar; ölçüm/kampanya çalıştırmaz ve yayın kapısı değildir.
- [ ] Yerleşik hedef veya gerçek yayın tarihi alanı yoktur; GitHub Release zamanı dış gerçektir.
- [ ] Proje Sürümleri alanı taranabilir genel görünüm sunar; Sürüm Kanıt Paketi bu ticket'ta yoktur (64).
- [ ] Kabul kanıtı Project Release Planning seam'inde: oluşturma, kapsam, tip karşıtı.
