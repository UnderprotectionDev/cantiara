# 05 — Bağlam içi önizleme ve koleksiyona kaydetme kapısı

**What to build:** Kanban, Birleşik Takvim, Roadmap, Kapsam Ağacı, Akıllı Koleksiyon ve Bildirim Merkezi `Open source record` ile varsayılan geçici yan panelde kaynağı açar. Panel kopya veya kalıcı yerleşim değildir; `Open full page` derin çalışma içindir. Panel oturumlar arası recent-context olarak dönmez. Filtrelenmiş arama `Save as Smart Collection` ile 34’e devredilir; geçici arama kendiliğinden koleksiyon olmaz.
