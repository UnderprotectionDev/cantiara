# 01 — Planlı Test Senaryosu sürümleri

**What to build:** Kurucu Planlı Test Senaryosunu başlık, amaç, kapsam, önkoşul, beklenen davranış, isteğe bağlı not ve ilişkilerle sürümlü Proje kaydı olarak tutar. Senaryo test çalıştırmaz, canlı adım yüzeyi açmaz, sonuç taşımaz ve bağlı Özellik/Sürümü doğrulanmış saymaz. Anlamlı değişiklik yeni sürüm üretir. Senaryo İş kontrol listesi, Test Oturumu veya Handoff paketi değildir.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Senaryo sürümlü niyettir; runner, sonuç ve doğrulanmış hükmü yoktur.
- [ ] Senaryo Test Oturumu veya Handoff paketi değildir.
- [ ] Anlamlı değişiklik yeni sürüm açar.
- [ ] İş kontrol listesi semantiği yoktur.
- [ ] İngilizce UI `Planned Test Case` kullanır; eksik etiket PRD sözlüğüne aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Planned Tests and Handoff seam'inde: sürümleme, runner yokluğu. Kanıt [Test kabulü](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) paket sözleşmesinin senaryo yarısıdır.
