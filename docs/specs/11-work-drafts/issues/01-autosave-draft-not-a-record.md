# 01 — Otomatik Taslak ve ana kayıt olmaması

**What to build:** Çevrimiçi İş oluşturma formu kişisel `Draft` olarak otomatik korunur. `Drafts` yüzeyinden sürdürülür veya silinir; süreyle silinmez. Taslak anahtar, arama, planlama, ilişki, bildirim, paylaşım, yayın ve export’a girmez. Yakalama öğesi veya Belge taslağı değildir. Özel alanlar 10’un İş bağından çizilir; Taslak şema tanımlamaz.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Autosave yalnız bağlantı varken sunucuya yazar; Taslak ana kayıt kimliği almaz.
- [ ] `Drafts` listeler; zaman ilerletme silmez; silme İş etkilemez.
- [ ] Evrensel Arama, Backlog, ilişki ucu, paylaşım, yayın ve export Taslak göstermez / kabul etmez.
- [ ] Taslak kesinleşene kadar İş anahtarı, Proje Etkinliği veya Kayıt geçmişi olayı üretmez.
- [ ] İş’e bağlı Proje bazlı özel alanlar 10’dan çizilir; Taslak ikinci şema tanımlamaz.
- [ ] İngilizce `Draft` / `Drafts` terim tablosuna aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Work Drafts seam'inde autosave, arama karşıtı, süre karşıtı. [Taslak](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari).
