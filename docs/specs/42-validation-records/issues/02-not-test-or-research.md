# 02 — Test ve araştırma ile karışmama

**What to build:** Deney/Doğrulama Planlı Test Senaryosu, Test Oturumu veya kullanıcı araştırması oturumu değildir. Sonuç formal test yönetimi veya kabul raporu yerine geçmez. Aynı kayıt Geri Bildirim sayılmaz.

**Blocked by:** 01 — Yöntem, sonuç ve karar bağlamı

**Status:** ready-for-agent

- [ ] Test Oturumu, Planlı Test Senaryosu, Oturum Testi veya Test Açığı olarak açılamaz ve onların yaşamını taklit etmez.
- [ ] Kullanıcı Araştırması Oturumu veya Geri Bildirim türüne dönüşmez.
- [ ] Kayıt yayın veya test raporu kabul kapısı değildir.
- [ ] Kabul kanıtı aynı seam’de tür karşıtları: test/araştırma/geri bildirim değil, kapı değil.
