# 02 — Kapalı semantik küme ve editör ortakları

**What to build:** Akış yalnız `Screen`, `Action`, `Decision`, `State/Outcome`, `Section` kümesini kullanır. Metin ve sınırlı erişilebilir görsel stil vardır; keyfî şekil veya renge ürün semantiği yüklenmez. Çoklu seçim, pan, zoom, sığdırma, hizalama, katman sırası, grid, copy/paste, klavye ve güvenli undo bu uzman editörün kabul davranışıdır. React Flow adaptördür; kalıcı model Tasarım kaydının sürümlü akış belgesidir, herkese açık xyflow JSON sözleşmesi değildir. Teknik Sıra türleri yoktur.

**Blocked by:** 01 — Canlı Ekran referansları ve kırık hedefler

**Status:** ready-for-agent

- [ ] Küme dışındaki düğüm türü ürün semantiği kazanmaz ve kaydedilmez.
- [ ] Renk/şekil ikinci tür sistemi değildir.
- [ ] Editör ortakları (çoklu seçim, pan/zoom, hizalama, undo) çalışır.
- [ ] Teknik Sıra / durum makinesi türleri yoktur.
- [ ] Moodboard veya Proje Duvarı bu akış yüzeyi değildir.
- [ ] Kabul kanıtı aynı seam'de: kapalı küme reddi, Teknik Sıra yokluğu, ortak düzenleme eylemleri.
