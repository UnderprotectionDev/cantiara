# 01 — Canlı kartlar, yerleşim kaynağı yazmaz

**What to build:** Kurucu birden fazla düz, adlandırılmış Proje Duvarı tutar; duvarlar iç içe geçmez ve yalnız Proje kapsamındadır. Kalıcı öğeler mevcut ana kayıtların canlı kartlarıdır; duvara özgü not, görev veya dosya yoktur. Aynı kayıt farklı duvarlarda kopya içerik olmadan referanstır. Kartı kaydırmak veya yoğunluğunu değiştirmek kaynak kaydı yazmaz; içerik `Open Source Record` ile ana kayıtta düzenlenir. `Compact` / `Preview` / `Detailed` ürünün seçtiği alanları gösterir; serbest CSS veya kart başına alan oluşturucu yoktur.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Duvar Proje kapsamlı, düz ve adlandırılmıştır; iç içe veya Çalışma Alanı duvarı yoktur.
- [ ] Kart kaynak kimliğini korur; kopya kayıt üretmez; duvara özgü not/görev/dosya yoktur.
- [ ] Duvar Wireframe, Moodboard veya Wiki sayfası değildir.
- [ ] Yerleşim ve yoğunluk kaynak alan, durum, öncelik veya ilişki yazmaz.
- [ ] İngilizce UI `Project Wall`, `Compact`, `Preview`, `Detailed`, `Open Source Record` kullanır; eksik etiketler PRD sözlüğüne aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Project Wall seam'inde: canlı kimlik, yerleşimin kaynağı yazmaması. Kanıt [Proje Duvarı](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) canlı kart E2E'sidir.
