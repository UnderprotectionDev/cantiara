# 04 — Sunum ve iç bölge snapshot'ı

**What to build:** Presentation Mode düzenleme araçlarını gizler; odak sırası görünüm üstverisidir, ikinci dosya veya içerik kopyası değildir. Seçili grup veya bölge snapshot'ı tarihli PNG/PDF'dir, donmuş kopya olarak adlandırılır, duvarı kilitlemez, paylaşım kapsamını genişletmez. Dış yüzey yayını ve Build in Public bu ticket'ta yoktur. Teknik Diyagram kartı salt okunur canlı önizlemedir; duvarda düğüm düzenlenmez. Akıllı Koleksiyon özeti kendi sorgusunu oluşturmaz.

**Blocked by:** 01 — Canlı kartlar, yerleşim kaynağı yazmaz

**Status:** ready-for-agent

- [ ] Snapshot donmuş kopyadır; canlı kartlar çalışmaya devam eder.
- [ ] Önizleme çıktının paylaşım izni olmadığını söyler; 73/75 UI'si açılmaz.
- [ ] Presentation Mode ikinci içerik kopyası üretmez.
- [ ] Diyagram kartında düzenleme yoktur; koleksiyon bloğu ikinci sorgu değildir.
- [ ] Kabul kanıtı aynı seam'de: snapshot–canlı fark, paylaşım kapsamı karşıtı. [Proje Duvarı](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) snapshot testidir; kapalı dünya paylaşımı 73/75'tedir.
