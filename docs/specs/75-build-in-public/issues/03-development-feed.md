# 03 — Onaylı gelişim akışı

**What to build:** Herkese açık gelişim akışı yalnız kurucunun yayımladığı tarihsel öğeleri, kaynak özel bağlamını açmadan kronolojik Proje hikâyesi olarak gösterir. İç yorum, özel ilişki ve taslak yoktur. Feed otomatik bütün Proje Etkinliğini dökmez; Geri Bildirim feed'i veya Bildirim Merkezi değildir. Roadmap yayın farkındaki isteğe bağlı `Explain the change` aynı yayın olayına bağlı durabilir; sistem cümle üretmez ve alan zorunlu değildir.

**Blocked by:** 02 — Aynı revizyondan Roadmap, changelog ve Proje görünümü

**Status:** ready-for-agent

- [ ] Akış yalnız onaylı tarihsel öğeleri gösterir; onaysız etkinlik, taslak, iç yorum ve özel ilişki yoktur.
- [ ] Öğeyi seçmek kaynak özel Workspace kaydını ziyaretçiye açmaz.
- [ ] `Explain the change` kurucu yazısıdır, zorunlu değildir, AI üretmez, ikinci plan gerçeği olmaz.
- [ ] Akış aboneliği, yorumu ve oyu yoktur.
- [ ] Kabul kanıtı Build in Public seam'inde: onaylı üyelik, otomatik-döküm karşıtı, özel bağlam sızıntısı yokluğu.
