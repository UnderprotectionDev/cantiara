# 01 — Nötr kaynak özet modülleri

**What to build:** Tek Proje genel bakışı amaç, yaşam durumu, Proje Hedefi girişi, eşzamanlı aktif aşamalar, kilometre taşları, güncel iş, belgeler, kararlar, riskler, aktif Test Handoff’ları, son Test Oturumları, açık Test Açıkları, önemli üretim olayları, blokajlar, yaklaşan/geçen hedef tarihler ve son değişiklikleri kaynak kayıtlarından nötr özetler. Otomatik sağlık hükmü veya başarı anlatısı yoktur. Açık Soru nitel belirsizlik modülü yoktur.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Modüller seed edilen kaynaklarla dolar; kaynak yoksa dürüst boş durum vardır, uydurma satır yoktur.
- [ ] Sağlık skoru, traffic-light veya başarı anlatısı alanı yoktur.
- [ ] Workspace overview, Değer Zinciri ve Manuel Proje Güncellemesi bu yüzeyde karışmaz.
- [ ] Test Handoff / Test Oturumu / Test Açığı özeti Testler alanı ürünü değildir; Planlı Test Senaryosu veya Handoff yüzeyi burada oluşmaz.
- [ ] Proje Hedefi Overview’dan ad ve görünür girişle açılır; ayrı gizlenebilir Proje alanı değildir.
- [ ] Açık Soru Overview belirsizlik/sağlık modülü değildir; görünürlük İş Bağlam Kartındadır.
- [ ] İngilizce modül adları PRD terim sözlüğüne aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Project Overview seam'inde kaynak eşitliği ve skor karşıtı. [İlk Proje](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) overview yarısı.
