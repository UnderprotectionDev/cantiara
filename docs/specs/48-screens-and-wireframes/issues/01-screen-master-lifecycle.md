# 01 — Ekran ana kayıt yaşamı

**What to build:** Kurucu Ekranı Proje kapsamında bağımsız kimlik, geçmiş, ilişki ve yaşam döngüsüyle tutar. Yalnız başlıkla, henüz görsel tasarım olmadan oluşturulabilir. Wireframe bağımsız ana kayıt veya ayrı arşiv/silme yaşamı değildir; kesin sürümler Ekrana tarihsel bağlı kalır. Arşiv, Çöp Kutusu ve geri yükleme ortak ana kayıt davranışını izler. Silinen Ekran başka yüzeyde kırık hedeftir; sessizce başka Ekrana bağlanmaz. Kullanıcı Akışı editörü burada yoktur.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Ekran başlıkla oluşur; görsel tasarım zorunlu değildir.
- [ ] Wireframe ayrı ana kayıt kimliği, kapsamı veya arşiv/çöp yaşamı kazanmaz; sürümler Ekrana bağlı kalır.
- [ ] Arşiv/çöp/geri yükleme ortak ana kayıt sözleşmesini izler.
- [ ] Silinen Ekran başka yüzeyde kırık hedeftir; sessizce başka Ekrana bağlanmaz.
- [ ] Kullanıcı Akışı editörü bu ticket'ta yoktur; Ekran Belge veya Moodboard çerçevesi değildir.
- [ ] İngilizce UI `Screen` kullanır; eksik etiket PRD sözlüğüne aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Screens and Wireframes seam'inde: başlıkla oluşturma, bağımsız Wireframe yaşamı yokluğu, sürümlerin Ekranda kalması. Kanıt [Tasarım bağlamı](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) Ekran yaşamıdır.
