# 01 — Geri dönüş kartları ve sıradaki somut adım

**What to build:** Ara verilen Proje veya İş için özet, güncel kayıtlardan son düzenlenen, son görüntülenen, yaklaşan tarihli, açık riskli veya bekleyen GitHub geliştirme sinyali bulunan az sayıda kart seçer. Her kart nedenini açıklar ve kaynağı açar. İsteğe bağlı `Next concrete step` o Proje veya İşin alanıdır; durum/öncelik/tarih/planlama değişince kendiliğinden yazılmaz.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Kartlar güncel kayıtlardan seçilir; eski snapshot güncel kayıt yerine geçmez. Yeni içerik veya ikinci çalışma listesi oluşmaz.
- [ ] Her kart gösterilme nedenini taşır ve `Open source record` ile ana kayda gider.
- [ ] `Next concrete step` isteğe bağlı tek metin alanıdır; ayrı kayıt, İş, kontrol listesi, Günlük Odak, hatırlatma veya ikinci liste değildir. Yeni değer etkin ipucunun yerini alır, eskiler normal geçmişte kalır.
- [ ] Alan durum, öncelik, tarih, planlama üyeliği veya aşama değişince kendiliğinden güncellenmez veya silinmez; olaylardan adım tahmin edilmez.
- [ ] Özet yönlendirilmiş seans, zorunlu gündem veya kayıt durumu yazan akış değildir.
- [ ] Kabul kanıtı Return to Work seam’inde: kart nedenleri, güncel kayıt, alan yazmama, otomatik adım yokluğu. [kişisel bağlam](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari).
