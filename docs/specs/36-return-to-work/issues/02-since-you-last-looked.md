# 02 — Son baktığından beri

**What to build:** Özet, ilgili Proje veya desteklenen İş bağlamına son başarılı görünür açılıştan sonraki tanımlı olayları `Since you last looked` altında iş, karar, risk, belge, GitHub ve yayın gruplarında gösterir. İşaret Hesaba aittir, analytics veya denetim olayı değildir; kayıt silinince silinir, dış yüzeye açılmaz.

**Blocked by:** 01 — Geri dönüş kartları ve sıradaki somut adım

**Status:** ready-for-agent

- [ ] Son ziyaret işareti Hesapta, Proje ve desteklenen İş bağlamı başına tek zaman damgasıdır; görüntüleme geçmişi, süre, analytics veya Denetim kaydı üretmez.
