# 01 — Görsel referanslar ve köken

**What to build:** Kurucu Moodboard'da görselleri Dosya Eki veya dış bağlantı kökeni ve isteğe bağlı kısa altyazıyla düzenler. Altyazı yorum dizisi, reaksiyon, görev veya ikinci dosya açıklaması değildir. Referans üretim varlığı veya Ekran değildir. Moodboard düzenlemek Proje Duvarı kartı otomatik oluşturmaz.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Her görsel köken ve isteğe bağlı altyazı taşır; köken kaybolmaz.
- [ ] Altyazı sosyal dizisi veya ikinci doğruluk kaynağı değildir.
- [ ] Referans Ekran veya üretim varlığı kimliği almaz.
- [ ] Moodboard Kullanıcı Akışı, Wireframe veya tasarım sistemi değildir.
- [ ] Duvar kartı otomatik oluşmaz.
- [ ] İngilizce UI `Moodboard` kullanır; eksik etiket PRD sözlüğüne aynı değişiklikle eklenir.
- [ ] Kabul kanıtı Moodboards seam'inde: köken korunumu, otomatik duvar kartı yokluğu. Kanıt [Tasarım bağlamı](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) Moodboard yarısıdır.
