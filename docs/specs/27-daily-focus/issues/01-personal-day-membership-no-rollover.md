# 01 — Kişisel gün üyeliği, yuvarlanma yok

**What to build:** Günlük Odak, kurucunun farklı Projelerden seçili takvim gününde ele almak istediği İşleri kişisel görünümde toplar. Eklemek veya çıkarmak durum, öncelik, proje aşaması veya Backlog sırasını değiştirmez. Üyelik o güne aittir, paylaşılmaz ve ertesi güne otomatik taşınmaz. Bu yüzey Odak Dönemi, sprint, Takvim olayı veya Aktif Çalışma Seti değildir.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Seçili profil günü için kişisel üyelik İş kimliklerini tutar; paylaşım veya ikinci Hesap göremez.
- [ ] Ekleme/çıkarma durum, öncelik, aşama ve Backlog sırasını yazmaz.
- [ ] Ertesi gün otomatik üyelik taşımaz; dünün kümesi bugüne kopyalanmaz.
- [ ] İngilizce UI `Daily Focus` kullanır.
- [ ] Kabul kanıtı Daily Focus seam’inde üyelik karşıtı ve yuvarlanma yokluğu. Kanıt [Günlük planlama](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) yolculuğuna bağlanır.
