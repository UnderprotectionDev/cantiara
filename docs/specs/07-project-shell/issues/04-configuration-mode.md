# 04 — Yapılandırma modu

**What to build:** `Configuration Mode` aşama, İş durumu adı, etkin alan, özel alan giriş, öncelik ölçütü, kayıtlı görünüm ve İş Bağlam Kartı düzen girişini günlük içerik düzenlemesinden ayırır. Mod izin veya yönetici rolü değildir; açıkça görünür ve tek eylemle kapanır. Mode girmek kayıt, üyelik veya Proje yaşamını değiştirmez. Günlük oluşturma/düzenleme/durum/planlama mod dışında kalır. Özel alan şeması bu ticket’ta tanımlanmaz.
