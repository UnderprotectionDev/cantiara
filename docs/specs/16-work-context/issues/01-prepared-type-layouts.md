# 01 — Beş türün hazır düzeni

**What to build:** Feature, Bug, Task, Research ve Improvement kendi kapalı hazır bölüm setini kullanır. Düzen yalnız İş türüne göredir ve `Blank Project`, `Solo SaaS`, `Open Source Library`, `Mobile Application` içinde aynı başlangıç anlamını taşır. Bölümler `Add Context` ile aşamalı açılır; oluşturma veya durum geçişi kapısı değildir.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Beş türün hazır bölüm seti [İş Bağlam Kartı](../../../prd/06-work-management-and-planning.md#iş-bağlam-kartı) tablosuyla birebir aynıdır.
- [ ] Dört Başlangıç yapılandırmasında aynı tür aynı düzeni görür; yapılandırma İş anlamını bölmez.
- [ ] Başlık, tür, durum ve günlük planlama alanları başlangıçta görünürdür; diğer bölümler `Add Context` ile açılır.
- [ ] Hiçbir bölüm oluşturmayı veya durum geçişini engellemez; boş bölüm kaydı durdurmaz.
- [ ] İngilizce bölüm adları ve `Add Context` PRD terim sözlüğüne aynı değişiklikle bağlanır.
- [ ] Kabul kanıtı Work Context Card seam'inde beş tür × dört yapılandırma matrisi. Kanıt [İş bağlamı](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) yolculuğudur.
