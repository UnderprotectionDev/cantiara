# 01 — Genel bakış modülleri ve canlı bloklar

**What to build:** Çalışma Alanı genel bakışı `Active Projects`, `Attention Required`, `Upcoming` ve `Recent Work` ile açılır. Özetler kaynak kayıtlardan türetilir; sayı ve başlık kesin kümeyi açar. Kurucu dört modülü gösterir, gizler ve sıralar; sınırlı sayıda mevcut Belge veya adlandırılmış Akıllı Koleksiyon görünümünü kopyasız kişisel canlı blok olarak ekler. Modül sağlık hükmü, serbest widget veya Proje Genel Bakışı/kişisel kabuk değildir.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Dört hazır modül kaynak kayıtlardan türetilir; tıklanan sayı/başlık kesin filtrelenmiş kümeyi `Open source record` ile açar.
- [ ] Modül bağımsız sağlık hükmü üretmez; sayı kaynak kümesini açar, Project health alanı veya Mission Control toplaması değildir.
- [ ] `Active Projects` Active Projeleri listeler; `Upcoming` yaklaşan kaynak tarihleri; `Recent Work` son dokunulan İşleri gösterir. Recency Favori veya Aktif Çalışma Seti yazmaz.
- [ ] `Attention Required` başka yerde kayıtlı kaynak dikkatini toplar; yeni sinyal kimliği veya Bildirim Merkezi üretmez.
- [ ] Dört modül gösterilir, gizlenir ve sıralanır; gizlemek kaynak kaydı silmez.
- [ ] Sınırlı Belge veya adlandırılmış Akıllı Koleksiyon bloğu referanstır; gövde/üyelik kuralı kopyalanmaz; kaynak değişince blok değişir.
- [ ] Kullanıcı tanımlı genel widget ve serbest dashboard builder yoktur. Kişisel Wiki Proje özeti gibi durmaz.
- [ ] Genel bakış ikinci Workspace veya dashboard gerçeği değildir.
- [ ] Bu yüzey Proje Genel Bakışı veya kişisel erişim kabuğunun yerine geçmez; Çalışma Alanı ufkudur.
- [ ] İngilizce UI `Active Projects`, `Attention Required`, `Upcoming`, `Recent Work` kullanır.
- [ ] Kabul kanıtı Workspace Overview seam'inde: dört modül, drill-down, layout, canlı blok, Wiki karşıtı. Kanıt [İlk Proje](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) genel bakış dilimidir.
