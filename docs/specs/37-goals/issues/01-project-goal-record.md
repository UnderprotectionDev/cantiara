# 01 — Proje Hedefi kaydı

**What to build:** Kurucu Projede başlık, açıklama, isteğe bağlı `Intended outcome` ve sonradan yazılan `Observed outcome / learning` ile Proje Hedefi tutar. Sistem ölçüm izlemez, gerçekleşeni doldurmaz, yüzde veya sağlık üretmez. Hedef Kilometre Taşı, Proje Sürümü veya Key Result değildir. Ayrı Proje alanı açılmaz.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Proje Hedefi Proje kapsamlı ana kayıttır; açık/kapalı yaşam üretmez. Sonuç kullanıcı alanlarındadır.
- [ ] Key Result, yapılandırılmış hedef/gerçekleşen çifti, otomatik birleştirme ve bağlı kayıtlardan ilerleme yüzdesi yoktur.
- [ ] İngilizce UI `Project Goal`, `Intended outcome`, `Observed outcome / learning` kullanılır; eksik etiket terim sözlüğüne aynı değişiklikle eklenir.
- [ ] İlk Proje Hedefsiz açılabilir; başlangıç yapılandırması sahte Hedef üretmez.
- [ ] Kabul kanıtı Project Goals seam’inde: kayıt, otomatik yüzde yokluğu, Key Result yokluğu. [İlk Proje](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) Hedef zorunlu kılmaz.
