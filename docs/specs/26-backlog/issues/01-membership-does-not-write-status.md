# 01 — Hazır üyelik durum yazmaz

**What to build:** Backlog, henüz planlanmamış İşler dahil değerlendirilmesi gereken bütün aktif, arşiv ve çöp dışı İşlerin hazır dinamik koleksiyonudur. Bir İşi Backlog’da görmek, ele almak veya başka planlama görünümüne almak İş akışı durumunu değiştirmez. Klasör, etiket, sprint veya ikinci İş listesi oluşmaz.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Backlog aktif, arşivsiz, çöpsüz İşleri planlanmamışlar dahil gösterir; üyelik saklı statik liste değildir.
- [ ] Görüntüleme, ele alma veya başka yüzeye alma durum, kapanış sonucu veya proje aşaması yazmaz.
- [ ] Arşiv ve Çöp Kutusu kayıtları hazır kümede yoktur.
- [ ] İngilizce UI `Backlog` kullanır.
- [ ] Kabul kanıtı Backlog seam’inde üyelik/ele alma karşıtının durum yazmaması. Kanıt [Günlük planlama](../../../prd/16-product-acceptance.md#uctan-uca-kabul-yolculuklari) yolculuğuna bağlanır.
