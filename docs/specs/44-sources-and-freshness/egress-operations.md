# Smart Link Preview egress

The product API calls `SMART_LINK_EGRESS_URL`, an HTTPS `/preview` endpoint. Without it, previews remain plain links. There is no in-process or local-worker fallback in the product API.

Use the existing Railway deployment boundary for a **separate service in a separate project/network**. Give this service no product private-network routes, database/R2/auth/GitHub credentials, shared volumes, service references, or environment imports. Run as a non-root user with a read-only application filesystem, a writable temporary directory, and a 256 MB service memory limit. Only `PORT` is needed by the service. Restrict ingress to the application caller at the edge and apply the existing Cloudflare WAF / Rate Limiting boundary. Do not expose an unrestricted public proxy.

Build with the server's existing build command, then start with `bun run --cwd apps/server start:egress`. The build emits `smart-link-egress.mjs` and `smart-link-egress-worker.mjs` alongside the product API. Ship the egress entrypoint, worker, shared build chunks and required runtime dependencies; never ship `.env` files. `GET /health` returns `ok`.

Each request runs a fresh worker with an empty environment and `--no-env-file`, no account or cookie input, and no database/auth imports. Four workers maximum; the whole worker is killed after 12 seconds. Network work has a 10 second budget, at most three redirects per resource, standard HTTP(S) ports, 16 KB response headers and a 20 MB total resource budget. Compression is refused, keeping wire and decoded size identical. HTML/plain text is limited to 1 MB before parsing; capture text is limited to 100,000 characters. Every DNS answer and redirect is validated, and a fresh undici dispatcher pins one validated address per hop with the original Host/TLS name. Cookies, auth, proxy agents, redirects and credentials are never inherited.

Images are optional: the same DNS/redirect policy applies, with at most 5 MB and 16 million decoded pixels. Only JPEG/PNG/WebP are decoded and rewritten as a metadata-free WebP thumbnail (512×512 maximum). No external image URL reaches the browser. Embedded HTML, SVG and provider embed markup are never returned. YouTube oEmbed is checked on this same egress path; only an exact YouTube URL can expose a player id.

Deployment is an operational prerequisite, not completed by an issue implementation. Verify network isolation and resource limits in the deployed service, then configure the API's HTTPS endpoint. Automated preview tests use a network double at the Sources and Freshness seam; they do not prove a Railway project's firewall configuration. UI tests use the same preview contract and a YouTube API double; live provider availability is not deterministic acceptance evidence.
