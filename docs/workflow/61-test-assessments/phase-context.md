# Test Değerlendirmeleri

Kurucu seçili test bağlamı için tarihli kabul edilebilir, takip gerekli veya karar verilmedi snapshotı kaydeder. Yeni bağlam eski hükmü güncel gerçek gibi göstermez.

Hüküm tarihli kalır. Yeni senaryo veya sürüm eski değerlendirmeyi sessizce taşımaz.

Bu feature test değerlendirmelerini tamamlar. Test özeti, inceleme ve sürüm kanıt paketi ayrıdır.

## Tamamlanma Ölçütleri

- Seçili test bağlamı için tarihli kabul edilebilir, takip gerekli veya karar verilmedi snapshotı kaydedilir.
- Yeni bağlam eski hükmü güncel gerçek gibi göstermez.

## Kapsam Sınırları

- Değerlendirmeyi yayın kapısı veya kalite skoru sayma.
- Eski snapshot'ı yeni sürüme otomatik taşıma.
- Değerlendirmeyi Test Oturumu sonucu sayma.
