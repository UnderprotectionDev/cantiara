# Test Açığı

Kurucu henüz denenmediğini veya yetersiz doğrulandığını düşündüğü alanı başlık, gerekçe ve dayanak ilişkileriyle kaydeder. Sistem başarısız testten, eksik senaryodan veya benzerlikten otomatik açık üretmez.

Açık Risk, Bug veya Ürün Boşluğu değildir. Kapanış seçili Oturum Testleriyle manuel olur. Testler alanı bu kaydı gösterir; ayrı test ürünü veya faz değildir.

Bu feature Test Açığını tamamlar. Test incelemesi, Test değerlendirmesi ve rapor kabulü ayrıdır.

## Tamamlanma Ölçütleri

- Test edilmemiş veya yetersiz doğrulanmış alan açıkça kaydedilir.
- Kapanış seçili Oturum Testleriyle manuel olur; başarısızlıktan otomatik açık doğmaz.
- Açık coverage yüzdesine indirgenmez.

## Kapsam Sınırları

- Başarısız testten otomatik açık üretme.
- Açığı Risk, Bug veya Ürün Boşluğu sayma.
- Testler alanını bu kaydın sahibi veya ana faz yapmak.
