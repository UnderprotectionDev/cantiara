# Proje Genel Bakışı

Kurucu tek Projenin amacı, yaşam durumu, aşamaları, güncel işi, bilgisi, belirsizliği, testi, sürümü ve olaylarını nötr bir kaynak özetiyle görür.

Proje dağınık yüzeylerden toplanmadan okunur. Özet başarı anlatısı veya otomatik sağlık skoru üretmez; kaynaklara açılır.

Bu feature proje genel bakışını tamamlar. Manuel güncelleme, kapanış özeti ve test alanı kendi kayıtlarını taşır.

## Tamamlanma Ölçütleri

- Tek Projenin amacı, yaşamı, işi, bilgisi, belirsizliği, testi, sürümü ve olayları nötr kaynak özetiyle görünür.
- Özet otomatik sağlık hükmü veya başarı anlatısı üretmez.

## Kapsam Sınırları

- Genel bakışı dashboard skoru veya durum kapısı sayma.
- Manuel Proje Güncellemesini otomatik özetle karıştırma.
- Çalışma Alanı genel bakışını tek Proje özeti yapmak.
