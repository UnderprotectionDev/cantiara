# Proje Sürümü Planlama

Kurucu yayımlanacak kapsamı Proje Sürümünde yönetir. Terminal sonuçlar yalnız açık eylemle değişir ve GitHub Release veya dış yayın bunu örtük tamamlamaz.

Sürüm, Kilometre Taşı veya Odak Dönemi değildir. Kapsam bilinçli kapanır; dış etiket Cantiara sonucunu yazmaz.

Bu feature proje sürümü planlamayı tamamlar. Sürüm kanıtı, iletişim ve paylaşım yüzeyleri ayrıdır.

## Tamamlanma Ölçütleri

- Yayımlanacak kapsam Proje Sürümünde yönetilir.
- Terminal sonuçlar yalnız açık eylemle değişir; GitHub Release veya dış yayın bunu örtük tamamlamaz.

## Kapsam Sınırları

- Sürümü Kilometre Taşı, Odak Dönemi veya GitHub Release sayma.
- Dış etiketin Cantiara kapanış sonucunu yazması.
- Sürümü otomatik kapsam doldurma veya skor kapısı yapmak.
