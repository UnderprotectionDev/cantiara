# Sürüm Kanıt Paketi

Kurucu Sürüm kapsamı, PR ve check, Karar, Risk, test sonucu, Test Açığı ve yayın farkını tek değerlendirme yüzeyinde kaynaklarına açar. Sistem yayın skoru veya otomatik kapı üretmez.

Yayına dair kanıt dağılmaz. Kurucu eksikleri görür; sistem "yayınla" demez.

Bu feature sürüm kanıt paketini tamamlar. Test özeti, PR kartı ve sürüm planlama kendi kayıtlarını taşır.

## Tamamlanma Ölçütleri

- Kapsam, PR/check, Karar, Risk, test, açık ve yayın farkı tek yüzeyde kaynaklarına açılır.
- Sistem yayın skoru veya otomatik kapı üretmez.

## Kapsam Sınırları

- Paketi otomatik yayın kapısı veya kalite skoru sayma.
- Eksik kaynağı sessizce yok sayma.
- Paketi sürüm notu veya kapanış özeti yapmak.
