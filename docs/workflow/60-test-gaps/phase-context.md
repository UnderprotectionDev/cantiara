# Test Açıkları

Kurucu test edilmemiş veya yetersiz doğrulanmış alanı açıkça kaydeder ve seçili Oturum Testleriyle manuel kapatır. Sistem başarısızlıktan otomatik açık üretmez.

Boşluk görünür kalır. Başarısız test, açık uydurmaz; kapanış seçili kanıta bağlanır.

Bu feature test açıklarını tamamlar. Risk, ürün boşluğu ve değerlendirme açık kaydı değildir.

## Tamamlanma Ölçütleri

- Test edilmemiş veya yetersiz doğrulanmış alan açıkça kaydedilir.
- Kapanış seçili Oturum Testleriyle manuel olur; başarısızlıktan otomatik açık doğmaz.

## Kapsam Sınırları

- Başarısız testten otomatik açık üretme.
- Açığı Risk, Bug veya Ürün Boşluğu sayma.
- Açığı coverage yüzdesine indirgeme.
