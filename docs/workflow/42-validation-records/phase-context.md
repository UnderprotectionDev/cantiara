# Deney ve Doğrulama Kayıtları

Kurucu ürün dışında yürüttüğü varsayım veya soru doğrulamasının yöntemini, sonucunu ve karar bağlamını kaydeder. Bu kayıt formal test yönetiminin yerine geçmez.

Dışarıda yapılan denemenin yöntemi kaybolmaz. Sonuç, Test Oturumu veya kabul kapısı sayılmaz.

Bu feature deney ve doğrulama kayıtlarını tamamlar. Test senaryoları, araştırma oturumları ve test raporu kabulü ayrıdır.

## Tamamlanma Ölçütleri

- Ürün dışında yürütülen doğrulamanın yöntemi, sonucu ve karar bağlamı kaydedilir.
- Kayıt formal test yönetimi, Test Oturumu veya yayın kapısı yerine geçmez.

## Kapsam Sınırları

- Deney kaydını Test Senaryosu veya Test Oturumu sayma.
- Sonucu otomatik Varsayım durumu veya Karar yapmak.
- Kaydı kullanıcı araştırması oturumu sayma.
