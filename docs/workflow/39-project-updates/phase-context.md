# Manuel Proje Güncellemeleri

Kurucu tarihlendirilmiş öznel sağlık işareti, kısa anlatı ve kaynak snapshotıyla Proje değerlendirmesi kaydeder. Bu kayıt güncel otomatik sağlık hükmüne dönüşmez.

Kurucunun o günkü hükmü tarihli kalır. Yeni kayıt eskisini silmez; sistem "proje sağlıklıdır" diye konuşmaz.

Bu feature manuel proje güncellemelerini tamamlar. Proje genel bakışı, kapanış özeti ve üretim olayı ayrı kalır.

## Tamamlanma Ölçütleri

- Tarihli öznel sağlık işareti, anlatı ve kaynak snapshotı Proje değerlendirmesi olarak kaydedilir.
- Kayıt güncel otomatik sağlık hükmüne dönüşmez.

## Kapsam Sınırları

- Güncellemeyi canlı sağlık skoru veya durum kapısı sayma.
- Eski değerlendirmeyi silip tek güncel hükme indirgeme.
- Güncellemeyi sürüm notu veya kapanış özeti yapmak.
